# 문경관광공사 공직비위 익명신고센터

문경관광공사(Mungyeong Tourism Corporation)의 **내부 공직비위 익명신고** 웹사이트입니다.
임직원 및 수탁 관계자의 부정·비리·갑질·이해충돌 등을 익명으로 접수하고,
신고번호로 처리결과를 확인할 수 있도록 구성한 **완전 오리지널 디자인**의 정적 프런트엔드입니다.

> 이 프로젝트는 특정 외부 기관의 사이트를 복제한 것이 아니라, 문경관광공사 자체 브랜딩으로 새로 제작되었습니다.

## 구성

**프런트엔드 (정적)**

| 페이지 | 설명 |
|--------|------|
| `index.html` | 센터 소개 · 익명성 안내 · 신고 범위 · 처리 절차 |
| `report.html` | 신고 접수 폼 (유형·내용·증빙 첨부·비밀번호 설정, 서버에서 신고번호 발급) |
| `result.html` | 신고번호 + 비밀번호로 처리상태·담당자 메시지 조회 및 추가 메시지 전송 |
| `faq.html` | 자주 묻는 질문 (아코디언) |
| `css/style.css` | 공통 스타일 (문경 숲 컬러 테마, 반응형, 접근성) |
| `js/common.js` | 내비게이션·FAQ 공통 스크립트 |
| `js/report.js` | 신고 접수 폼 검증 및 서버 전송 |

**백엔드 (`server/`)** — 암호화 저장 + 관리자 콘솔

- 신고 내용·첨부파일을 **AES-256-GCM**으로 암호화 저장, 비밀번호는 **bcrypt** 해시
- 익명 조회 API, 신고자↔담당자 메시지, 관리자 콘솔(`/admin/`: 열람·상태변경·첨부 복호화)
- 자세한 설치·실행·보안 설계는 [`server/README.md`](server/README.md) 참고

## 로컬 미리보기

```bash
# 저장소 루트에서
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 배포

- **프런트엔드만** 간단히 올릴 경우: GitHub Pages, Netlify, Vercel 등 정적 호스팅에 배포 (단, 신고 저장은 백엔드 필요).
- **전체 서비스**: `server/`를 Node 호스팅(사내 서버, Docker 등)에 배포하면 프런트엔드까지 함께 서빙됩니다. 반드시 **HTTPS** 뒤에서 운영하세요.

설치·실행·운영 하드닝 체크리스트는 [`server/README.md`](server/README.md)에 정리되어 있습니다.

## 보안 요약

구현 완료:
- ✅ 서버 측 **암호화 저장**(AES-256-GCM): 신고 내용·첨부·메시지·파일명
- ✅ **비밀번호 해시**(bcrypt): 신고/관리자 비밀번호
- ✅ 서버 발급 **신고번호**, 서버 측 조회 검증, 조회 실패 시 타이밍 완화
- ✅ **IP 미로깅**, 관리자 API 인증(JWT), 민감 파일 웹 비노출, rate limit, Helmet/CSP

운영 전 조직에서 확인할 사항(자세한 내용은 `server/README.md`):
1. HTTPS 적용 및 `NODE_ENV=production`(secure 쿠키)
2. 리버스 프록시(nginx 등) 신고 경로 `access_log off`
3. `MASTER_KEY`의 KMS/시크릿 매니저 관리 및 백업·로테이션
4. 첨부 EXIF 등 메타데이터 제거(필요 시)
5. 「공익신고자 보호법」 고지·개인정보 처리방침 법무 검토
6. 관리자 접근 IP 제한·2FA 등 정책 강화
